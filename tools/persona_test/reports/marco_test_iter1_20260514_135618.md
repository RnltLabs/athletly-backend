## Recommendations

1. **Make temporal_freshness gate auto-execute sync_garmin_data**: don't just warn the model, force the tool call as a pre-response action when athlete mentions fresh activity.
2. **Block ship on threshold-pace fabrication specifically**: Marco's profile says threshold_pace_min_km: 5.30 but persona text says "threshold UNKNOWN". Either fix the seed inconsistency or add a hard rule that derived thresholds need a confidence flag.
3. **Eliminate request_garmin_connect retry loops**: track if request has been rendered in current session; if rendered and user dismissed, don't re-render.
4. **Fix internal_error during save_plan**: save_plan executor hitting Anthropic rate-limit at week 10 is a hard production bug; needs retry-with-backoff or partial save.
5. **Strengthen stats_grounding to also catch English-term-in-German**: the language_mirror gate flagged Body Battery but shipped anyway.
6. **Investigate turn 4 mid-stream rewrite**: this is a positive behavior. Replicate the pattern that triggered it across other turns where the critic flags violations.

1. **Threshold-pace hallucination still ships despite stats_grounding gate** - The Schwellenpace bug regressed from 5:30 to 5:18 but is fundamentally unfixed. The critic flags it in real time, the gate language is seen, but the response ships unchanged. This is the surviving iter 0 defect.
